## Статус

Проект стабильно работает в режиме обучения: PPO + C++-среда (**49 действий**,
obs v2 = **299** flat / миникарта **8×32×32** глобальная), канонический профиль
наград — `configs/reward_v4.json` (терминальный бонус за выживание, дисциплина
кредитов, предналоговое давление).

**2026-09-20 закрыты два пользовательских бага** (подробности и протоколы —
в [CHANGELOG.md](CHANGELOG.md)):

- обучение в режиме `hybrid` падало на первом шаге
  (`TypeError: linear(): … must be Tensor, not tuple`) — контракт `obs_mode`
  между `EnvManager` и сетью теперь явный (`_obs_mode()`, `_split_hybrid_obs()`,
  `ActorCriticHybrid._split_obs`), регрессия `tests/test_trainer_bootstrap.py`;
- наблюдение за чемпионом в GUI-окне («галочка GUI-окно → ничего не происходит»)
  получило handshake, таймауты, heartbeat в лог, ограниченные рестарты,
  перехват вывода окна, per-run IPC-каталог, убийство дерева процессов и
  атомарную запись с обеих сторон — `docs/GUI_WATCH_2026_09.md`,
  регрессия `tests/test_watch_visual.py` (18 тестов, фейковое окно вместо exe).
  Попутно: прерванный прогон (без `final_model.pt`) снова виден в списке моделей.

Синхронизация дефолтов закрыта (2026-09-19): C++ `RewardConfig` и дефолт
obs приведены к канону (v4 / obs v2) на всех границах. Прогон под Linux:
`cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build`
(нужны pybind11, numpy, pytest; расширение — `python/colony_cpp*.so`).
Локальные проверки: `./scripts/cpp_checks.sh` (22 пробы + 7 проверок) и
`python -m pytest` (43 тест-файла; без собранного `colony_cpp` часть тестов
падает на импорте — это признак окружения, не регрессии). **CI зелёный**
(2026-09-20, PR #13): `C++ пробы` и `colony_cpp + pytest` — первый успешный
прогон `.github/workflows/ci.yml`.

## Известные ограничения (не баги)

- `survival_coeff`/`goal_survival_coeff` v4: деньги сами по себе дают награду
  только через терминальный бонус — это осознанное решение (P0-1 диагностики).
- Приоритеты ресурсов (`curriculum_resources`) действуют только на реально
  добываемые ресурсы; `w_food = w_gold = 0` всегда по построению (нет
  зданий-потребителей).
- `loop_detector` по умолчанию ВЫКЛЮЧЕН (`loop_detection_enabled=False`).
- Eval — детерминированный argmax с замороженной нормализацией; это не та же
  политика, что при обучении (сэмплирование).
- `final_model.pt` пишется только в конце обучения: у остановленного/упавшего
  прогона есть лишь `best_model.pt` и чекпойнты — это нормальная модель
  (см. README §8.2).
- Наблюдение в окне — lock-step и однопоточное: скорость упирается в рендер
  окна или инференс на CPU; `state.json` текстовый (~100 КБ/шаг с миникартой),
  бинарный протокол в план не входил (`docs/GUI_WATCH_2026_09.md` §7).
- `minimap_radius` сохранён только для совместимости API: миникарта глобальная
  32×32, на наблюдение радиус не влияет (P2-8, `DeprecationWarning`).

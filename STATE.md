## Актуальные баги / проблемы (по приоритету)

1. **WaterChannel заблокирован маской почти 100% времени**
   Измерено: 0/2000 шагов в случайном роллауте. Водоканал не строится **не из-за
   наблюдения**, а из-за маски действий + BFS `find_lot()` (вода на карте).
   Разбор: `docs/REVIEW_WATER_MODES_2026_09.md`. Следующий шаг — диагностика
   условия легальности BUILD_WaterChannel в `src/env.cpp` и `find_lot()`
   (src/earth.cpp): почему «водный» лот не находится на типовых картах.
2. **Спам дорогами = аргмакс функции награды**
   Измерено: +898 (road-spam) против −233 (работающая экономика) на профиле v3.
   Профиль v4 (`docs/AUDIT_REWARD_2026_09.md`) призван это переломить —
   **требует верификации на длинном прогоне** (зонд `tests/cpp/reward_audit_probe.cpp`).
3. **exp_25/26/27 требуют 56+ ГБ VRAM** (n_envs=1024) — на типовом GPU не
   запускаются. Нужны уменьшенные варианты конфигов (N12).
4. **Расхождение документации:** README (раздел «Карта проекта») ссылается на
   `auto_trainer.py`, `training_cycle.py`, `observe.py`, `sweep*.py` — этих
   файлов в репозитории нет (удалены при чистке 2026-09-11, README не обновлён).
5. **`tests/test_ui2_smoke.py` исключён** в `pytest.ini` (`addopts`) — причина
   исключения не задокументирована; решить: починить или удалить.
6. **Полный прогон pytest требует** `torch` + собранный `colony_cpp`
   (`build_pyext.bat` на Windows; под Linux проверено 2026-09-19:
   `cmake -B build && cmake --build build` с pybind11/numpy/torch —
   318 passed, 2 skipped; для CI осталось автоматизировать окружение).

## Известные ограничения (не баги)

- `survival_coeff`/`goal_survival_coeff` v4: деньги сами по себе дают награду
  только через терминальный бонус — это осознанное решение (P0-1 диагностики).
- Приоритеты ресурсов (`curriculum_resources`) действуют только на реально
  добываемые ресурсы; `w_food = w_gold = 0` всегда по построению (нет
  зданий-потребителей).
- `loop_detector` по умолчанию ВЫКЛЮЧЕН (`loop_detection_enabled=False`).
- Eval — детерминированный argmax с замороженной нормализацией; это не та же
  политика, что при обучении (сэмплирование).
